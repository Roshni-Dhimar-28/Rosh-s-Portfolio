## ✨ About

This portfolio is more than a collection of projects. It is designed as a digital journal that reflects my journey as a developer.

Instead of a traditional portfolio layout, every section feels like a notebook page filled with memories, projects, creativity, and personality.

From handwritten typography to illustrated stickers and interactive animations, every detail was carefully crafted to create a memorable experience.

- 📖 Journal-inspired UI

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/your-username/portfolio.git
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
